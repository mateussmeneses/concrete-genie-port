# Roadmap

1. PROMPT 01: auditoria, SHAs, comparação, baseline original e evidências (etapa atual).
2. Bootstrap em branch própria: separar perfil, caches/saves/configuração e hooks; testes de rejeição de build desconhecida; corrigir somente bloqueios demonstrados. Exige revisão do resultado de 01.
3. Auditar dump fornecido pelo operador: SFO, hashes, imports, módulos e recursos específicos. Sem dump: somente fixtures sintéticas, nunca uma build suportada fictícia.
4. Boot por primeiro bloqueio observável, depois menu, gameplay, áudio, saves e integridade GPU.
5. Regressões de cache frio/quente, frame pacing, memória, iluminação, mouse/menu e outras GPUs; distribuição em Windows limpo.

Ver o playbook original para critérios completos das etapas futuras. Esta lista não redefine o objetivo de gameplay real nem autoriza presets/otimização especulativa.
